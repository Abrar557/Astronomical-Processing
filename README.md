# Astronomical-Processing
Sprint One <br>
Program Description:<br>
 This program simulates astronomical data processing by generating a list of random neutrino interaction values. <br>
Users can search for specific values using binary search, sort the data using bubble sort, and edit values directly in the displayed list.<br>
The program checks if the array is sorted before allowing binary search, and it highlights the found value in the list when found.<br>

Inputs: <br>
 - A user-specified value in the search box to find in the neutrinoData array.<br>
 - Button clicks to trigger sorting and searching functionalities.<br>
 - Double-clicking on the list to edit a specific neutrino interaction value.<br>

 Processes:<br>
 - Generating an array of random integers to simulate hourly neutrino interactions.<br>
 - Sorting the array using the Bubble Sort algorithm.<br>
 - Searching for a user-inputted value using Binary Search.<br>
 - Editing an element of the array through a double-click interaction on the list box.<br>

 Outputs:<br>
 - Sorted array displayed in the list box.<br>
 - Search result message showing if a value was found or not.<br>
 - Highlighted value in the list box when the binary search finds the specified value.<br>
 - User input box for editing a list item.<br>
 - A message box displaying confirmation of the edit.<br>
